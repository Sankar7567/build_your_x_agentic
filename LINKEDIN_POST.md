🚀 Just launched my 100 Days of Agentic Engineering challenge! 

Inspired by the classic "Build Your Own X" philosophy (like https://github.com/codecrafters-io/build-your-own-x), I'm committing to build AI agents from scratch—no heavy frameworks like LangChain, AutoGen, or CrewAI allowed.

🎯 **The Goal**: Master the core primitives of autonomous AI systems by implementing one agentic component per day for 100 days, using only Python standard library, Pydantic, HTTPX, and raw LLM APIs.

📚 **The Curriculum**: Progresses through 5 levels:
- **Level 1 (Days 1-20)**: Core primitives like ReAct loops, tool engines, context management
- **Level 2 (Days 21-40)**: Specialized skills—web scraping, API agents, database explorers
- **Level 3 (Days 41-60)**: Multi-agent systems—orchestration, communication protocols, consensus
- **Level 4 (Days 61-80)**: Advanced infrastructure—memory graphs, safety guards, telemetry
- **Level 5 (Days 81-100)**: The Final Bosses—autonomous DevOps, full-stack generators, AI software engineer platforms

🔧 **Why Build From Scratch?**
Most tutorials abstract away the fascinating complexities that make agents truly work. By building the foundational pieces ourselves—reasoning loops, tool execution, memory management, multi-agent coordination—we gain deep intuition that transfers to any framework or production system.

📂 **Repository Structure**: 
Each day has its own directory with:
- Detailed Software Requirements Specification (SRS)
- Recommended tech stack
- Architecture breakdown
- Acceptance criteria
- Implementation hints (to be filled in as I code)
